# Social / short-form

Short-form post bundles, one per phase (plus recurring cadence posts).

**Per-phase bundle** — paired with the long-form writeup in `../writeups/`:

- Teaser post — "here's what we just shipped, here's the writeup."
- Headline-result post — the one chart or one finding that matters most.
- Call-to-engage post — a question or open challenge to the building community.

**Recurring cadence** (once the lab is producing):

- Monthly retrospective thread — what shipped, what surprised us, what's next.
- Model-of-the-month leaderboard update (Phase 6+).
- Reading-list / paper threads when a paper directly informs a lab decision.

**Workflow:**

1. Draft as `phase-N-<slug>.md` (per-phase bundle) or `YYYY-MM-<topic>.md` (recurring) in this folder.
2. Each draft contains the platform-specific variants (LinkedIn paragraph, X thread, Bluesky/Mastodon variants as needed) under labelled headings.
3. Record published URLs at the top of each variant.
4. Cross-link to the writeup, the relevant experiment folders, and the public leaderboard (Phase 6+).

**House style:** evidence-first (numbers and screenshots over claims), no AI-marketing tone, link generously back to the repo. Short-form is a doorway to the long-form; don't try to land the full argument in 280 characters.
